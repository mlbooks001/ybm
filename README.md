# YBM FC 축구팀 홈페이지 ⚽

YBM FC 축구팀의 공식 웹사이트입니다.

## 📋 프로젝트 소개

HTML, CSS, JavaScript로 제작된 축구팀 홈페이지로, 회원 관리, 뉴스 게시, 경기 기록 관리 등의 기능을 제공합니다.

## ✨ 주요 기능

### 사용자 페이지
- 🏠 **메인 페이지**: 팀 소개, 선수단, 경기 일정, 최신 뉴스
- 🔐 **로그인/회원가입**: LocalStorage 기반 회원 인증
- 📰 **뉴스 보기**: 이미지와 함께하는 뉴스 상세보기

### 관리자 페이지
- 👥 **회원 관리**: 회원 조회 및 삭제
- 💰 **회비 관리**: 납부 현황 관리 및 통계
- ⚽ **선수 관리**: 선수 정보 CRUD
- 📅 **경기 일정 관리**: 예정 경기 관리
- 📊 **경기 기록 관리**: 경기 결과 및 득점 기록
- 📰 **뉴스 관리**: 뉴스 작성 및 이미지 첨부 (자동 압축)

## 🚀 시작하기

### 로컬에서 실행
1. 저장소 클론 또는 파일 다운로드
2. `index.html` 파일을 브라우저로 열기
3. 완료!

### 관리자 로그인
- **아이디**: admin
- **비밀번호**: admin123

## 📁 파일 구조

```
YBM-FC/
├── index.html          # 메인 페이지
├── login.html          # 로그인 페이지
├── register.html       # 회원가입 페이지
├── admin.html          # 관리자 페이지
├── styles.css          # 메인 스타일시트
├── admin-styles.css    # 관리자 스타일시트
├── auth.js            # 인증 및 뉴스 로드 스크립트
└── admin.js           # 관리자 기능 스크립트
```

## 💾 데이터 저장

- LocalStorage를 사용한 클라이언트 측 데이터 저장
- 이미지는 Base64로 인코딩하여 저장 (자동 압축)

## 🛠️ 기술 스택

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- LocalStorage API
- Canvas API (이미지 압축)
- FileReader API

## 📱 반응형 디자인

모바일, 태블릿, 데스크톱 모든 기기에서 최적화된 UI를 제공합니다.

## 🔧 주요 기능 상세

### 이미지 자동 압축
- 최대 너비: 1200px
- 압축 품질: 80%
- 평균 70-90% 용량 감소

### 실시간 통계
- 대시보드에서 실시간 데이터 확인
- 회원수, 선수수, 경기수, 뉴스수
- 회비 납부율 및 승률 자동 계산
